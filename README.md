# V-System · 吉他和弦实验室

本地运行的 Ted Greene V-System 四声部吉他和弦工具。原生 HTML / CSS / JavaScript，无第三方依赖、无构建步骤、无 CDN，断网也可使用。

## 启动

**Windows 推荐：双击 `start.cmd`。** 启动本地服务并打开默认浏览器。当前电脑已安装 Node.js，可直接使用。关闭服务窗口或按 `Ctrl+C` 停止。

也可以在本目录打开终端：

```powershell
npm start
```

浏览器访问 <http://127.0.0.1:4173>。如果端口被占用，自动尝试后续 20 个端口，请以终端显示的地址为准。默认只监听本机 `127.0.0.1`。如需自定义：`$env:PORT=8080`，然后 `npm start`。

**零安装方式：直接双击 `index.html`。** 所有核心功能也可在 `file://` 页面使用；浏览器对本地文件的设置保存行为可能不同。若没有 Node.js，`start.cmd` 会自动打开这个离线版本。

## 使用

1. 选择根音和四音和弦性质，支持大七、属七、小七、小大七、半减七、减七、增大七、增属七、属七降五、大六、小六、挂四属七、挂二属七，共 13 种。
2. 用六个琴弦按钮恰好选中四根弦；支持不相邻弦，也可使用低四弦 / 中四弦 / 高四弦快捷按钮。选弦期间不足或多于四根会提示，选满后自动搜索。
3. 选择 V1–V14，查看原位及三个转位。每张卡片独立切换位置，按跨度、把位从小到大排序。在“试听音色”中选择木吉他或清音电吉他，再点击 ▶，用真实吉他录音由低到高试听。音色选择会自动保存，切换时保留当前指型位置。
4. 搜索范围固定为 0–24 品，可设置最大按弦跨度。默认不含空弦；勾选“包含低把位空弦指型”后，空弦只允许搭配 1–5 品的按弦，不会混入高把位指型。切换设置自动重新搜索；有效设置尽可能保存在当前浏览器。
5. 当前条件无解时会明确提示，并在可行时提供其他弦组按钮。尝试放宽跨度或更换弦组。
6. 默认隐藏同一指型整体升高 12 品的重复位置，保留较低的把位。勾选“显示高八度重复指型（+12 品）”可查看全部位置；不同形状、不同声部跨弦的指型仍分别保留。

## 指板方向与标记

- **琴弦是水平线、品丝是竖线。高音 1 弦 E4 在顶部，低音 6 弦 E2 在底部。**
- 琴头与低品位在左，高品位向右；图下方是实际品位数字，每个图会自动显示当前指型所在范围。图中不显示低／高品位提示。
- 实心点标和弦级数（如 `1 / ♭3 / ♭5 / ♭7`），颜色依次对应四个构成音。空弦为琴枕左侧描边圆。图左侧仅保留调弦音名，不显示弦号或不弹标记。
- 图右侧逐行显示每根弦的品位数，与对应琴弦对齐，按 **1 → 6 弦** 从上到下排列，`×` 表示不弹。卡片底部仅保留位置切换，不显示跨度与把位说明。
- 卡片上方音序按 **实际音高从低到高** 排列；可能与物理弦顺序不同，此时显示“声部跨弦”。卡片标题里的低音决定转位，绝不假设最粗的已选弦一定是最低声部。
- 按弦跨度 = 非零品位的最大值 − 最小值；空弦不计入。带空弦的指型另有限制：所有按弦品位必须在 1–5 品。跨度为几何筛选，不等同于人体工学保证；没有推断左手指法、横按或手指编号。
- 超宽跨度时，手机上指板可横向滚动查看；13 种和弦的音名按级数拼写，例如 Cdim7 为 C / E♭ / G♭ / B♭♭，F♯maj7 的七音为 E♯。

## V-System 的实现依据

V 指 Voicing，而非调内属和弦。以 James Hober 整理的 **Method 2 — Chord Tone Gap Method** 为准。B / T / A / S 是从低到高的 Bass / Tenor / Alto / Soprano；gap 表示两个相邻声部之间可插入的和弦音数量，**不是半音数**。

| 组 | B–T | T–A | A–S |
|---|---:|---:|---:|
| V1 | 0 | 0 | 0 |
| V2 | 1 | 0 | 1 |
| V3 | 0 | 1 | 2 |
| V4 | 2 | 1 | 0 |
| V5 | 1 | 2 | 1 |
| V6 | 4 | 0 | 0 |
| V7 | 5 | 0 | 1 |
| V8 | 2 | 2 | 2 |
| V9 | 1 | 0 | 5 |
| V10 | 1 | 4 | 1 |
| V11 | 2 | 1 | 4 |
| V12 | 4 | 1 | 2 |
| V13 | 0 | 4 | 0 |
| V14 | 0 | 0 | 4 |

对每个转位，从指定低音沿四个构成音循环前进 `gap + 1` 步，保留所有八度距离。例如 Cmaj7 原位：V1 = C–E–G–B；V6 = C–高八度 E–G–B；二者音级顺序相同，但真实间距不同。

程序枚举整体八度位置及四个声部到四根弦的 24 种分配，核验实际音高、品位、空弦和跨度限制。因此保留 V 组间距，也能找到声部跨弦的真实解。结果不是静态指型库，不对音级简单取模后随意补八度。

四张卡片的低音依次为和弦四个构成音。六和弦与挂留和弦也按这一方式循环；卡片显式标注具体低音与级数，方便辨认。此工具没有声称覆盖 Hober 的全部 43 种四音和弦性质。

## 吉他采样

试听使用下载并随项目分发的真实吉他录音。木吉他有 35 个采样音（E2–D5，逐半音），清音电吉他有 16 个采样音（E2–C6）；其他音高由最近的录音移调得到。和弦保留原本的实际音高与八度间距，四个音由低到高拨奏。音色加载失败会明确提示并允许重试。

录音来自 [N. P. Brosowsky 的 tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments)，原始作者分别为 University of Iowa 和 Karoryfer，采样许可证为 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。已裁去开头静音并截取最多 4.5 秒，转为单声道 MP3，再封装成项目内的两个数据包。详细来源、版本与修改记录见 [assets/LICENSE.md](assets/LICENSE.md)。

页面首次点击某种音色时加载对应的数据包（木吉他约 3.2 MB，电吉他约 1.5 MB），之后复用已加载的录音。文件保存在项目内，启动本地服务或直接双击 `index.html` 均可播放，无需连接第三方音色服务。

运行 `npm test`，无需安装依赖。覆盖 V1–V14 精确八度、已知 Cmaj7 指型、变音拼写、13 种性质 × 14 组 × 4 转位 × 15 种弦组、跨弦、独立穷举对照、低把位空弦限制、八度去重与边界筛选，以及录音数据、采样移调、加载取消与重试、HTTP 服务文件范围。
