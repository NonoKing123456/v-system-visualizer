## 环境与启动

原生 HTML / CSS / JavaScript，项目 `package.json` 要求 Node.js 18 或以上，没有安装依赖或打包步骤。

```powershell
npm start
npm test
```

服务只监听 `127.0.0.1`，默认 4173，端口被占用时按终端提示使用后续端口。Windows 也可双击 start.cmd；没有 Node 时启动脚本回退到 index.html。直接打开页面时，核心计算和本地采样可用，但存储行为依浏览器而异。

## 代码边界

`engine.js` 是浏览器与 Node 共用的纯计算入口，负责音名、和弦级数、V 组音程和指型搜索。`app.js` 组织设置、卡片及 SVG 指板，`guitar-audio.js` 处理本地采样和播放；不要把 Node 测试 API 放入浏览器脚本。

`server.cjs` 使用固定文件表，不是任意目录文件服务器。新增页面资源时，除文件本身还需核对服务白名单和 MIME 类型；不要为方便把整个个人工作目录公开。

## 算法约定

- V-System 使用和弦音间可插入音的数量，不把 gap 当半音数。
- 四声部按真实音高从低到高判定低音与转位，不假定弦序就是声部序。
- 保留真实八度与跨弦分配，不对音级简单取模后补任意八度。
- 0–24 品、跨度、低把位空弦、重复八度过滤分别检查。
- 指型几何成立不代表已推断手指编号、横按或人体工学可弹性。

理论来源、13 种和弦与 V1–V14 对照保留在首页。

## 测试

本次 Node `24.19.0` 下 `npm test` 的 12 项通过，覆盖计算、采样和 HTTP 文件范围。测试结果不代表真实吉他手可演奏每个结果，也不等于所有浏览器已实际试听。

修改交互时再打开浏览器，检查选弦、卡片位置切换、空弦筛选、真实音高试听和移动端横向滚动。本轮没有变更算法、音色包或 UI，也未重新制作截图。
