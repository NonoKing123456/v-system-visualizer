# 常见问题

[返回首页](../README.md) · [开发文档](DEVELOPMENT.md)

## 没有 Node.js 能用吗

可直接打开 index.html，start.cmd 也会回退到离线文件入口。Node 18 以上用于可选本地服务及测试。

## 搜索不到指型

先恰好选择四根弦，检查最大跨度、空弦限制和 V 组。某些真实八度排列本来就无法在所选弦组实现，尝试放宽跨度或换弦。

## V1 和 V6 看起来音名相同

V-System 保留实际八度与声部间距，相同音级顺序不代表相同配位；查看实际音高和品位。

## 为什么最粗的弦不是低音

声部按实际音高排序，跨弦时物理弦序与音高顺序可能不同，页面会提示声部跨弦。

## 第一次试听失败

点击播放以触发浏览器音频，确认本地 assets 数据包完整。音色加载失败可重试，不需要外部音色服务。

## 设置没有记住

设置属于当前浏览器存储，本地文件、不同端口或无痕模式可能不同。先记录关键选项，再清理浏览器数据。

## 仍无法解决

提交 Issue 时附版本或提交、系统环境、复现步骤与脱敏错误。优先提供合成文件，保留原数据与完整日志的本机备份。
